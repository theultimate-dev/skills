# Annotated directions: Fieldnotes

Fictional brief: help readers browse practical guides and choose one relevant to a current task. All directions show the same three titles, summaries, topic filter, and open-guide action. These are illustrative hypotheses, not research findings or a recommended universal aesthetic.

| Property | A: Reading room | B: Field index | C: Trail journal |
|---|---|---|---|
| Premise | Invite deliberate reading | Support quick scanning and retrieval | Make discovery feel exploratory |
| Composition | Wide introduction, followed by spacious stacked entries | Compact heading and aligned text rows | Introductory narrative followed by alternating text and small original diagrams |
| Type | Serif display and body with sans-serif labels | Sans-serif body and labels with restrained numeric markers | Sans-serif body with expressive serif section titles |
| Candidate body rhythm | 1.125rem / 1.65, 65ch measure | 1rem / 1.55, 60ch summaries | 1.0625rem / 1.6, 62ch measure |
| Spacing emphasis | 3rem sections, 1.5rem entry gaps | 1.5rem sections, 0.75rem row padding | 2.5rem sections, 1.25rem text/diagram gap |
| Color roles | Warm paper, dark ink, restrained green actions | Neutral surface, dark text, blue active state | Pale neutral surface, dark ink, rust accents |
| Narrow layout | Stack intro and filter; reduce display size | Stack row metadata below titles | Place each diagram after its text in reading order |
| Risk | Intro may delay access to guides | Dense rows may feel impersonal or crowded | Decorative storytelling may slow the task |

Candidate font stacks can begin with Georgia and system-ui for portable sketches, with their platform variation documented. They do not establish a final font choice. If the user is evaluating a specific face, embed an available redistributable font and show its actual weights and language coverage.

## What the sketches should resolve

Does A's introduction improve orientation or merely occupy space? Can B's summaries be scanned without cramped line spacing? Do C's diagrams explain guide topics or compete with the titles? Show the same long title in all three and inspect narrow and wide layouts before recommending a direction.

## Example convergence

The user chooses A's reading character and B's filter placement. Rewrite the selected brief as: retain A's serif hierarchy, body measure, and generous entry spacing; place the compact filter immediately after the collection heading; reduce the introductory paragraph to two sentences; preserve one-column entries. Keep A's token set and adjust only the control gap needed for the new placement.

This resolves a coherent combination. “Use the best parts of both” would leave the implementer to make the design decision again.
