# Annotated briefs

The following are fictional illustrations, not evidence about a real audience.

## Feature: filter saved guides

**Audience and outcome:** returning readers with an existing saved collection need to narrow it to a topic so they can choose something relevant now.

**Known context:** the user requested continuity with the existing design. Project inspection found topic tags and an existing collection. Existing account behavior is outside this change.

**Required:** R1, choosing a topic shows only matching guides and updates the visible result count. R2, clearing the filter restores the collection. R3, no matches explains the result and offers recovery.

**Acceptance example for R1:** with two Writing guides and one Research guide, choosing Writing displays the two Writing guides and reports two results.

**Excluded:** changes to saving guides, account management, recommendations, or a new taxonomy.

**Assumption:** one topic filter is sufficient for the first iteration. This is a scope choice to review with the user, not a finding about reader preferences.

**Annotation:** this brief is already useful for UX. A complete persona report or technical search architecture would add little at this stage.

## Proof of concept: topic labels

**Question:** can readers distinguish the proposed topic labels well enough to find an appropriate guide?

**Artifact:** a single offline collection screen with representative guide titles and three candidate labels. Use realistic sample content, marked fictional in companion notes.

**Evaluation proposal:** invite intended readers to find a guide for a concrete task; observe their first choice, hesitation, and explanation. Agree the recruitment and success criteria before conducting evaluation.

**Evidence sought:** confusion between the same labels suggests revising the taxonomy; successful navigation with clear explanations supports further exploration. A small convenience sample cannot establish broad usability.

**Excluded:** accounts, persistence, backend search, and deployment.

**Annotation:** producing the artifact satisfies the prototype task. It does not answer the learning question until someone evaluates it. Agent inspection can identify potential ambiguity but cannot substitute for participants.
