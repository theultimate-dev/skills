# Sprig: prototype context

Sprig is a command-line tool for one person who keeps houseplants. Adding, listing, removing and watering plants and the due list are built; ideas are tried as small bets.

This folder holds the product's context in Markdown beside its code. The code and the changelog sit outside it, in the same repository.

## Where to start

- [product/overview.md](product/overview.md): the product in one page.
- [bets/README.md](bets/README.md): the bets, built, kept and removed.
- [architecture/README.md](architecture/README.md): the structure.
- [decisions/README.md](decisions/README.md): why it is this way, and when this context moves to a fuller profile.
