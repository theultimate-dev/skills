# Plants (PLT)

Registering, naming, listing and removing plants.

| ID | Requirement | Status | Notes |
|---|---|---|---|
| PLT-01 | `add NAME --every DAYS` registers a plant with its interval | built | |
| PLT-02 | Plant names are unique, ignoring case | built | |
| PLT-03 | `list` shows every plant with its interval and next watering date | built | |
| PLT-04 | `remove NAME` deletes a plant | built | |
