# Fieldnotes

Fieldnotes is a fictional reading app that saves practical guides for noticing, learning and making things. There is no application code in this fixture.

The designs in `design/` are the project's source of truth. Every design page uses the shared foundations in `design/foundations/`, and views go in `design/views/<view>/`.
